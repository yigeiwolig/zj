# F2 MAX 固件

**F2 Max 与 F2 Ultra 为同一硬件、同一份固件。** 小程序里可能显示为「F2 Ultra」，烧录请始终使用本目录：

- `f2_max_servo.ino`

## 勿使用

`firmware/f2-ultra-servo/` 为历史重复副本，已废弃，所有修改只提交到 `f2-max-servo`。

## 近期固件要点（均在 f2_max_servo.ino）

- 打开堵转 / 回弹：仅 `selfCheckOn == 1`（开启自检）时运行
- 主动堵转检测最多 2 次：第 2 次收回后 Pin8 报警闪烁，不再重试
- 关钥匙 Pin9：由 `pin9HoldUntil` 锁定保持高电平至计时结束（至少 10 秒）；收回舵机期间 Pin9 不得拉低；Pin2 抖动前 3 秒内不取消保持
- 第二次受阻重试：阈值放宽 + 回弹迟滞，避免计数反复清零
- 自动调平、出行模式、延时断电、语音相关 BLE 指令等同在此文件维护
