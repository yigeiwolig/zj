F3 MAX 最新代码 — 需求整理（陀螺仪版，去掉 TOF）
================================================

一、产品定位
------------
- 固件目录名：F3_max_最新（中文「最新」必须带上）
- 以后不再使用 TOF / VL53 测高；姿态显示与骑行/过坑改用 MPU6050

二、删除（相对旧 F3 MAX）
------------------------
1. 全部 TOF / 测高相关：VL53、HGT、危险高度 DA/TB、高度监测 H0/H1、配置模式 M0/M1
2. 「牌照有没有收起来」的 TOF 检测：翻开后 ≥8cm 持续 8s → 红绿爆闪报警（F3W/折叠监视）全部去掉
3. 小程序自动标定测高向导（f3-cal-wizard / 危险高度·检测高度写入）去掉
4. 不做「防刮地保护」
5. 停车姿态自动翻板（倾斜展牌 / 扶正收回、PA 开关）已全部删除

三、MPU 保留能力
----------------
- 倾角显示 + 扶正(CU)/倾斜(CL) 标定（仅状态显示，不驱动翻板）
- 骑行：震动非 0 → 骑行中（双色灯）
- 过坑：冲击 → 红灯约 2s，期间锁物理按键翻板；小程序可发 BK 同步
- 翻板：仅手动（BTN5 / 蓝牙），无姿态自动动作

四、照明灯（D12 工作灯）
------------------------
- 小程序可手动开/关；默认仍可随牌照位策略

五、小程序同步
--------------
- 无「停车自动翻板」开关
- 保留：扶正/倾斜标定、照明灯、倾角/震动/骑行状态、过坑灵敏度

六、接线
--------
MPU6050：VCC/GND，SCL=A5，SDA=A4
D12：工作灯（照明灯）
其余舵机/按键/蓝牙与旧 F3 MAX 相同

七、已落地文件
--------------
firmware/F3_max_最新/F3_max_最新.ino     单文件固件
miniprogram/.../scan.*                  陀螺仪与照明设置
miniprogram/utils/f2FaultReport.js      解析 |MOK|/|IMS|/|IRD|/|IEV| 等

烧录：只烧 F3_max_最新.ino 这一个文件即可（Mixly / Arduino 均可）。
